# CMOS Studio

Static site: one `index.html`, no backend, no build step, no dependencies.

## Deploy to Vercel
1. Unzip, then drag the folder onto https://vercel.com/new, or run `npx vercel` inside it.
2. Framework preset: **Other**. Leave Build Command and Output Directory empty.
3. Deploy.

## Run locally
Open `index.html` in a browser.
